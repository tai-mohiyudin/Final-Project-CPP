# C++ Programs

## About Project
This repository contains different C++ programs created for learning and practicing C++ programming.

## Programs Included
1. **Animal Sounds** – Displaying sounds of different animals using classes and inheritance.
2. **Book Details** – Taking input and displaying book information.
3. **Person Details** – Managing person information using constructors, getters, and setters.
4. **Animal Polymorphism** – Demonstrating polymorphism using animal classes.
5. **Shape Polymorphism** – Calculating areas and displaying shapes using abstraction and polymorphism.

## Concepts Used
- Classes and Objects
- Inheritance
- Constructors
- Getters and Setters
- Abstraction
- Polymorphism
- User Input and Output

## Technologies Used
- C++
- VS Code

## Purpose
The purpose of this repository is to improve my C++ programming skills and understand Object-Oriented Programming (OOP) concepts through practical examples.
